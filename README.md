# ❄️ Snowflake to ML Pipeline 

### 📌 Project Overview
Integrated **Snowflake Cloud Data Warehouse** with a Machine Learning pipeline to predict EEG Eye State. This project demonstrates cloud database connectivity and model deployment using Random Forest.

### 🛠️ Tech Stack
* **Storage:** Snowflake (Cloud Data Warehouse)
* **ML Model:** Random Forest Classifier (Scikit-Learn)
* **Library:** `snowflake-connector-python`
* **Environment:** Google Colab

### 📊 Performance
* **Accuracy:** 92.1%
* **Key Features:** AF3, F7, F3, FC5, T7, etc. (EEG Sensors)
